目标分支：`codex/add-ai-project`

## 目标

在不覆盖或丢失现有五个项目内容的前提下，把新的 AI 运营工具项目加入首页首位，并把网站统一扩展为六项目编号体系。正式入口继续保持为根目录 `index.html`，本分支未经用户确认不合并至 `main`。

## 首页项目卡片

- 新项目作为 Project 01，类别为“AI项目”。
- 标题为“自制AI工具”，副标题为“vibe coding产物 · AI工作提效”。
- 卡片沿用现有项目列表的共同结构：`a > article`，article 内包含编号栏、主体内容和右侧徽标区，不增加专用卡片结构。
- 视觉色使用现有 Project 05 的 `#2b6b6b` 配色。
- 右侧只显示 `WEB PROJECT` 与 `>_`；尺寸、间距、位置和 DOM 层级沿用当前 Project 04 的右侧徽标布局。
- 原 Project 01 至 Project 05 依次顺延为 Project 02 至 Project 06，保留各自内容和视觉。
- 首页语言属性从 `lang="en"` 改为 `lang="zh-CN"`。

## 二级页

- 新建 `pages/project-01.html`，沿用现有二级页模板。
- 新页标题为“自制AI工具”，标识为“项目 01 · AI项目”，说明为“vibe coding产物 · AI工作提效”，计数为 `01 / 06`。
- 新页暂时保留现有 PPT 展示占位结构，不虚构项目数据或成果。
- 原 `project-01.html` 至 `project-05.html` 的完整内容分别迁移至 `project-02.html` 至 `project-06.html`。
- 所有页面标题、页内编号、标签编号和 `NN / 06` 计数与新文件编号一致。
- 返回链接继续使用 `../index.html#timeline`。
- 若当前文件中没有上一项/下一项导航，则不额外新增；若检查发现，则同步更新其链接。

## 资源与样式

- 保持 GitHub Pages 可用的相对路径。
- 不改名或删除现有资源。
- 优先复用现有工具类；只有新 HTML 确实引用尚未手写进 `assets/css/main.css` 的类时才补充 CSS。
- 不修改 `vendor.js`、`iconify.js` 或 `tailwind-config.js`，除非验证发现本需求无法在现有代码下实现。

## 验证

自动结构检查应验证：

1. `project-01.html` 至 `project-06.html` 全部存在。
2. 首页恰有六张项目卡片，链接依次指向对应二级页。
3. 六张卡片采用相同的顶层 DOM 骨架。
4. 原五个项目标题和正文内容均仍存在于顺延后的页面中。
5. 各二级页编号、标签编号及总数均为六项目体系。
6. 首页为 `lang="zh-CN"`。
7. HTML 引用的本地 CSS、JS、图片与二级页路径不存在 404。
8. 对修改分支执行 diff 检查，不自动合并 `main`。
