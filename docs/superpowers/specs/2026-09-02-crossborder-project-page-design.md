# 跨境项目管理二级页重设计

日期：2026-09-02  
本地分支：`codex/crossborder-project-page`

## 目标

将 `pages/project-04.html` 的 PPT 占位布局重构为面向面试官的完整案例页。页面以结果为入口，以项目过程和原始证据支撑个人能力，保持主站的视觉识别、静态 HTML 架构和 GitHub Pages 相对路径兼容性。本阶段只制作本地预览，不上传、不推送、不合并。

## 叙事原则

面试官在首屏应立即理解候选人负责了什么、项目规模多大、交付结果如何；继续浏览时能够看到任务拆解、标准建立、风险响应和质量管理的具体证据。页面所有项目事实、指标和结论均来自用户提供的 PPT，不补写无法验证的成果。

## 页面结构

1. 固定返回入口：左上角提供“返回作品集”，链接到 `../index.html#timeline`；同时显示 `PROJECT / 04` 与年份。
2. 项目首屏：标题聚焦“把 53,000+ 字交付变成一套可控流程”，配合两项项目、8 人协作、53,000+ 字、100% 按期交付四项指标。
3. 职责与能力：呈现项目排期与任务拆解、标准化与质量协同、数据化进度管理三项核心工作。
4. 推进流程：按需求接收、标准化、初译、校对、修订、交付组织案例过程，并说明 13 个里程碑节点。
5. 风险管理：原生网页提炼 PPT 中五类风险及对应处理，随后完整展示“项目里程碑与风险追踪”截图。
6. 标准前置：解释统一术语表如何把预计 3,000+ 处术语不一致降低到 1,240 处，并完整展示项目术语表截图。
7. 质量与结果：总结语义、语体、本地化三维审核，以及两项项目全部通过客户验收、100% 按期交付。
8. 方法论复盘：标准前置、看板驱动、三维审核、风险早判。
9. 页尾返回：再次提供返回作品集入口。

## 视觉系统

- 延续主站：米白 `#f4f1eb`、深炭黑 `#1a1a1a`、藏蓝 `#1a3b5c`、橙红 `#ea4313`。
- 淡黄色只用于少量文字高亮，不建立新的主色。
- 大号粗衬线体负责案例结论，精致小字号衬线体负责正文，全大写等宽字体负责项目元数据。
- 使用 1px 细分隔线、印章式标签、少量橙红手写批注和大面积留白，形成复古暖色报刊杂志感。
- 不复制 PPT 页面皮肤；PPT 只提供内容、结构与原始证据。

## 响应式与交互

- PC 使用最多 12 列的编辑网格；手机改为单列叙事，指标排列为 2×2。
- 两张截图保持完整内容，不裁剪、不额外脱敏；常规页面中按容器缩放并允许横向浏览。
- 点击截图打开原尺寸灯箱；灯箱支持关闭按钮、点击遮罩、`Escape` 键关闭和焦点返回。
- 动效仅包括轻微滚动显现、指标进入视口时渐显、截图悬停提示；`prefers-reduced-motion` 下停用非必要动效。
- 页面不依赖新的第三方运行库。

## 验证

1. 先修改结构测试，使其在旧页面上因缺少新结构而失败。
2. 完成页面与图片资产后运行 `tests/verify_portfolio.py`。
3. 检查本地引用、返回链接、图片灯箱、键盘关闭和减少动态效果逻辑。
4. 在 1440、1024、430、390 像素视口下检查布局、文字换行、截图浏览和点击区域。
5. 检查 `git diff --check` 与变更范围，确保没有改动其他项目和线上配置。
