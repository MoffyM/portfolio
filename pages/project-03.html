01 / OVERVIEW

我的职责不止是执行活动，而是设计门店端的用户路径。

CONTEXT

18 天项目周期

2023.09.28—10.15，覆盖国庆假期与主题活动窗口。

ROLE

门店端主导

主动提出联动机会，负责方案、触达、陈列、转化与社群运营；外部合作由上级及总部对接。

VALUE

兴趣流量商业化

用 IP 内容创造到店理由，再把兴趣流量导向联动商品、自有商品与社群。

02 / PROBLEM & INSIGHT

空间能留住人，但单一桌游体验不足以持续拉动消费。

门店已有优势

  • 高人流步行街商场，年轻客群集中
  • 停留时间长，社交娱乐需求明确
  • 已有桌游、大学生、情侣和二次元用户基础

需要解决的问题

  • 周边店以“即买即走”为主，体验深度不足
  • 商品购买频次有限，停留未充分转化
  • 需要兼具话题、稀缺性与传播性的到店理由
核心命题：如何把“兴趣人群”转化为“到店用户”，再把“到店体验”转化为“多品类消费”？
03 / USERS

人群交集：年轻化 × 泛二次元 × 社交娱乐 × 兴趣驱动消费。

CORE

女性向IP兴趣用户

关注角色内容、限定周边与线下打卡；情感连接和稀缺性驱动付费。

SCENE

桌游玩家 / 大学生 / 情侣

追求社交、娱乐与长时间体验，对新鲜主题活动接受度高。

OPPORTUNITY

电影 / 餐饮到访用户

已有娱乐消费目的，活动视觉和现场氛围可促成二次停留。

04 / MATCH & STRATEGY

选 IP 不是追热点，而是验证内容、人群与空间能否互相放大。

IP 侧：内容与稀缺性

女性向内容与商场、门店年轻用户高度重合；用户具备角色周边、限定内容与线下打卡需求。

门店侧：空间与社交体验

长停留空间适合合影互动；入口陈列获得自然曝光；桌游、饮品、撸猫等延长体验并带动连带消费。

AWARE

内容触达

小红书种草、微信通知、海报曝光。

VISIT

到店体验

主题打卡、官方周边、场景互动。

CONVERT

商品转化

入口陈列、浏览动线、讲解与组合推荐。

RETAIN

社群承接

问答互动、优惠券、预告、核销与 UGC。

围绕用户设计“触达—到店—转化—沉淀”，让每个运营动作都服务于下一步。
05 / CONTENT

宣传先回答三个问题：在哪里、什么时候、能获得什么。

小红书负责兴趣种草，微信社群负责精准通知，门店海报负责自然客流转化；共同强调“线下打卡 + 官方周边 + 城市地点”，降低用户决策成本。

06 / CONVERSION

现场转化的关键，是帮用户更快完成选择。

决策支持

  • 先判断用户是打卡、买谷还是体验门店
  • 用角色、品类和预算快速筛选
  • 推荐成套购买或搭配商品组合

连带消费

  • 用入口陈列承接第一眼兴趣
  • 用销售讲解降低选择成本
  • 自然介绍桌游、饮品等自有商品
自有商品贡献 16.8 万元、占活动期门店 GMV 的 40%，说明 IP 流量并未只停留在联动商品。
07 / COMMUNITY

社群不是通知群，而是活动之后仍能持续触达的关系。

WEEKLY

桌游 / 二次元问答

设置轻量问题，参与回答可获得优惠券，形成固定互动预期。

TRANSACTION

预告 / 到货 / 报名核销

及时发布活动和新品信息，把群内兴趣导向到店行动。

CONTENT

朋友圈桌游科普

持续介绍桌游玩法，降低新用户理解门槛并建立专业感。

SOCIAL PROOF

UGC / 老带新

鼓励晒单分享；邀请朋友到店可获得饮品等轻激励。

08 / SEGMENTATION

用户分层让同一场活动产生不同的下一步。

01

潜在兴趣用户

用主题视觉、活动时间和稀缺周边强化到店理由。

02

活动到店用户

用讲解、爆品陈列和组合推荐促进首次购买。

03

购买用户

引导进入社群，用活动与桌游内容持续触达。

04

核心社群用户

通过问答、优惠券、UGC 与老带新提升粘性。

09 / REVIEW

复盘不是包装成功，而是明确下一次要补上的数据链路。

当时的不足

  • GMV 结构依赖经营反馈和估算
  • 活动用户标签不完整，难追踪不同来源
  • 社群核销、复购和再次到店缺少完整口径

如果重做

  • 入群记录来源、兴趣 IP 和到店状态
  • 设置活动专属券码，追踪领取—核销—购买
  • 活动后按未到店、已到店、已购买分层触达
诚实识别数据与留存短板，才能把一次活动变成下一次增长的基础设施。
10 / CAPABILITY

把用户洞察翻译成可落地的运营动作。

01用户洞察：从场景、行为与社区内容识别真实需求，不以热点代替人群匹配。
02策略与转化：围绕用户旅程设计触达、体验、陈列、讲解和组合推荐。
03社群与迭代：建立持续触达关系，并用复盘补齐标签、核销与复购链路。
我在总部、上级与店长支持下主导门店端执行，也清晰理解合作与职责边界。
